# GitHub 开源项目雷达 (StarRadar)

> 自动发现 GitHub 高星开源项目的实时看板 —— 按总星标 / 增长最快 / 近期活跃多维排序，开箱即用。

单文件 HTML（约 84KB，零依赖、零构建），下载后用浏览器直接打开即可使用。全栈商用版（服务端 + 数据库 + 鉴权 + 会员付费）为同一产品的应用形态。

---

## 功能特性

| 模块 | 说明 |
| --- | --- |
| 三视图看板 | 总星标排行（按星标数从高到低）、增长最快（按星级增长速度排序）、近期活跃（24 小时内仍有提交的高星项目） |
| 实时数据 | 每次请求经服务端代理（或浏览器直连）调用 GitHub Search API，实时获取，无静态快照 |
| 搜索与筛选 | 关键词搜索（300ms 防抖）、按编程语言筛选、加载更多分页 |
| 顶部概览 | 收录项目数、总星标数、24h 活跃数、GitHub API 剩余配额 |
| 项目详情 | README 自动解析：功能摘要、安装/使用命令、效果图（协议白名单过滤）、项目信息、GitHub 链接、官网链接 |
| 使用方式流程图 | 每个项目内置取码 → 装依赖 → 配置 → 运行 的 SVG 流程图 |
| 中文翻译 | 一键把英文功能说明译成中文（真实在线翻译接口，失败保留原文），原文中文对照 |
| 源码下载 | 一键下载项目源码 ZIP 到本机 |
| 用户体系 | 注册 / 登录 / 退出，账号与会话本地持久化 |
| 会员付费 | 免费版（每日 3 次下载 / 5 次翻译）与专业版（不限次数 + 会员标识），演示支付流程 + 订单记录 |

## 快速开始

```bash
# 方式一：直接打开
git clone https://github.com/wenyuli6/github-star-radar.git
# 用浏览器打开 starradar.html 即可，无需任何安装
```

- 页面为纯前端单文件实现，数据实时来自 GitHub 公开 API，无需配置 Token（可选填 GitHub Token 可提升 API 配额）。
- 首次加载需联网获取数据；网络受限时页面有缓存兜底与友好错误提示。

## 数据说明

- 数据来源：`https://api.github.com/search/repositories`（GitHub Search API，公开数据）
- 增长速率口径：基于本地快照的星标历史测算日均增速
- 翻译接口：MyMemory 在线翻译（免费额度，失败自动降级保留原文）
- 下载链路：`https://github.com/<owner>/<repo>/archive/HEAD.zip`

## 商用全栈版

本仓库为**开源单文件版**；完整商用版为全栈应用（NestJS + React + 数据库 + 服务端鉴权），包含：

- bcrypt 加盐密码存储（cost=12，旧哈希自动迁移）
- 额度原子计数（唯一约束 UPSERT）、登录失败锁定、接口限流
- 支付事务化、README 图片协议白名单、会话滑动过期
- 依赖审计与错误日志分级 + trace-id 链路

商用版源码由产品发布方持有，开源仓库维护单文件版为主分支。

## 测试与安全

开源版已完成浏览器端到端验证（注册登录 → 详情 → 翻译 → 下载 → 会员支付 → 退出拦截，零 console error），并在数据层过滤 owner/name 缺失的异常项目条目、对下载/详情/翻译请求做参数校验（防止非法参数请求）。

商用版通过了 OWASP 十大类别代码级审查与 10 项商用加固，详见产品测试报告。
